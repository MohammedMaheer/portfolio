# Mohammed Maheer’s portfolio

The portfolio at [maheer.tech](https://maheer.tech/) is a static Vite site. Native scroll progress drives the AI walkthrough, the robot arm, the project reel, and the education scene. The campus chapter blends a Three.js model with a blue-hour illustration of the NMAMIT main block. Visitors who prefer reduced motion see the content in regular document flow.

```sh
npm ci
npm run dev
npm run build
```

Publish the contents of `dist/` to the web server. The site uses relative asset paths and requires no API keys. Update the content in `index.html` and replace the downloadable résumé at `public/images/my-cv.pdf`.
